Visual.Studio

100 images cinéma · image + prompt · même visage, autres habits, autres décors

Principe : ajoutez vos clés API (une par ligne), une image de référence et/ou un prompt texte. L'IA analyse et génère 100 images 9:16 — pellicule photographique uniquement, jamais 3D ni illustration. Le visage du héros est verrouillé par description textuelle ultra-précise injectée dans chaque prompt (l'endpoint de génération est text-to-image pur, donc on décrit le personnage avec la précision d'un portrait-robot). Chaque image affiche son prompt image et son prompt vidéo Google Flow copiables. Toutes les clés travaillent en parallèle.
